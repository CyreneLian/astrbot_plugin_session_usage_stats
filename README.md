# 📊 astrbot_plugin_session_usage_stats
# 🌸 模型用量统计插件

一款面向 AstrBot 的高性能模型用量统计与可视化仪表盘插件。支持统计全部模型在过去 24小时 / 7天 / 30天 / 1年 / 全部历史内的调用次数、Token 消耗（输入/输出/总额）与对话轮数；提供美观直观的 Web 仪表盘，涵盖趋势概览、模型与平台占比、Top 会话排行与明细表格；内置 30 天小时桶精细化自动瘦身与默认 1 年全量保留的双层清理机制，兼顾毫秒级极速查询与长久历史追踪。

## ✨ 功能特性

- 支持网页仪表盘（涵盖总览卡片、Top 会话排行、平台占比圆环图、模型占比圆环图、趋势概览折线图与明细表格搜索排序）
- 统计模型用量数据（涵盖过去 24 小时、过去 7 天、过去 30 天、过去 1 年与全部历史）
- 保留会话维度辅助统计，方便定位模型消耗来源
- 统计字段包括模型调用次数、输入 Token、输出 Token、总 Token、完成回复轮数与用户/Bot 消息数
- 支持模型调用统计（涵盖对话模型与全部模型维度，支持 Token 与次数切换）
- 支持 QQ / aiocqhttp 等不稳定写入历史库的平台通过事件捕获兜底统计
- 支持清空统计数据，并通过 `clear_at` 避免旧历史数据重新回流

## 🧪 已测试平台

> ⚠️ **本插件目前仅在以下两个平台经过完整测试，统计结果可以保证准确。其它平台虽可启用，但尚未经过完整测试，统计可能不准确、不完整或完全无数据。**

| 平台 | 是否经过完整测试 | 说明 |
| --- | --- | --- |
| `webchat`（AstrBot 网页聊天） | ✅ 已测试 | 统计准确，默认即启用 |
| ↳ 含 OpenAPI（外部 HTTP / WebSocket API 调用） | ✅ 已涵盖 | 复用 webchat 的会话、umo 与队列（`platform_id="webchat"`，umo 前缀 `webchat:FriendMessage:webchat!...`），归入 webchat 平台统计 |
| `aiocqhttp`（QQ / OneBot） | ✅ 已测试 | 需开启 `enable_event_capture: true` 才能稳定统计 |
| 其它平台（wecom_ai_bot / telegram / discord / matrix / feishu 等） | ❌ 未测试 | 自行验证后再使用，请勿依赖此插件做关键统计 |

### 📌 其它平台使用建议

如果需要在未测试的平台上使用本插件，建议：

1. **先在测试场景验证核心数据**：消息轮数、Token 消耗、Top 会话等是否正常落库
2. **开启自动扫描**：`enable_auto_scan: true`，并适当调大 `scan_batch_size` 防止漏扫
3. **留意主历史库写入情况**：插件依赖 `platform_message_history` 表的历史数据，未测试平台可能写入不完整
4. **使用「会话统计诊断」命令**：`会话统计诊断` 可以查看 Provider wrapper 接管情况
5. **若该平台依赖主历史库外的数据源**：可能需要自行扩展统计逻辑

### ⚠️ QQ / aiocqhttp 必开配置

由于 QQ 平台的消息历史写入不够稳定，强烈建议在配置中启用事件捕获，否则 QQ 的统计可能出现“用户消息数 > Bot 消息数”或部分会话数据缺失。

```text

├── main.py              # 插件主入口：处理指令注册、生命周期与事件捕获分发
├── core/
│   ├── __init__.py
│   ├── api.py           # Quart/Web API 路由处理器：向仪表盘提供数据接口
│   ├── database.py      # SQLite 数据库管理器：线程池异步读写、查询与清理
│   └── scanner.py       # 消息增量扫描器：异步补扫历史消息数据
├── models/
│   ├── __init__.py
│   └── config.py        # 插件配置模型：定义并校验各配置项参数
├── utils/
│   ├── __init__.py
│   └── decorators.py    # 数据库连接自动关闭等装饰器工具
├── metadata.yaml        # 插件元数据：名称、版本、作者、描述等
├── _conf_schema.json    # 插件配置页面 schema 定义
├── logo.png             # 插件图标
├── README.md            # 插件说明文档

    └── stats/

```

安装或更新后，请在 AstrBot 中重载插件，或直接重启 AstrBot。

## ⚙️ 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `enable_auto_scan` | bool | `true` | **是否开启自动扫描**（开启后每隔指定间隔自动增量扫描历史消息；关闭则仅在查询时补扫） |
| `auto_scan_interval_minutes` | int | `5` | **自动扫描间隔（分钟）**（仅在开启自动扫描时生效。设定增量扫描任务的执行间隔） |
| `scan_batch_size` | int | `500` | **单次扫描最大消息数**（防止单次扫描处理过多消息） |
| `enabled_platforms` | list | `["webchat"]` | **历史消息扫描的平台列表**（启用历史消息扫描的平台列表，适用于webchat等写历史表的平台，默认webchat） |
| `include_threads` | bool | `false` | **是否统计网页端线程对话**（开启后，网页端创建的「子线程对话」也会纳入用量统计；关闭则仅统计普通网页对话） |
| `enable_event_capture` | bool | `true` | **是否启用事件钩子捕获**（开启后，事件钩子会实时捕获消息并写库，适用于QQ等不写历史表的平台） |
| `event_capture_platforms` | list | `["aiocqhttp"]` | **事件钩子捕获的平台列表**（启用事件钩子捕获的平台列表，默认 aiocqhttp（QQ）） |
| `auto_cleanup_enabled` | bool | `true` | **是否开启自动清理旧统计数据**（开启后会在启动时及自动扫描后，删除超过保留天数的全量桶数据（日/周/月）。注意：为了精简数据库大小，超过 30 天的小时桶（hour）数据为系统固定自动清理，不受此开关影响） |
| `auto_cleanup_retention_days` | int | `365` | **全量统计数据保留天数**（仅影响插件自身数据库中的全量数据（日/周/月总账桶），开启自动清理旧统计数据后超过此天数的数据将被彻底清除） |

## 💬 聊天指令

| 指令 | 说明 |
| --- | --- |
| `会话统计 今日` | 查看当前会话过去 24 小时的用量统计 |
| `会话统计 本周` | 查看当前会话过去 7 天的用量统计 |
| `会话统计 本月` | 查看当前会话过去 30 天的用量统计 |
| `会话统计 模式` | 查看当前自动扫描、扫描间隔、单次上限、平台与事件捕获状态 |
| `会话统计 补扫` / `重扫` | 手动触发增量扫描，返回处理消息数、会话数与最新游标 |
| `会话统计诊断` | 查看 Provider 包装与模型调用记录情况，排查统计异常（需管理员权限） |
| `会话统计全部 今日` / `本周` / `本月` | 查看全站过去 24 小时 / 7 天 / 30 天的汇总统计 |

> **提示**：这里的“今日 / 本周 / 本月”均指滚动时间窗口（过去 24小时 / 7天 / 30天），非自然日 / 周 / 月。

## 📊 网页仪表盘

可在 AstrBot 插件页面直接打开“模型用量统计”网页（`pages/stats/index.html`）。

- **⏳ 时间范围切换**：支持 24小时 / 7天 / 30天 / 1年 / 全部历史
- **📋 总览卡片**：汇总显示会话数、总轮数、总/输入/输出 Token
- **🏆 Top 会话**：展示用量前 10 会话（支持按 Token / 轮数排序）
- **🥧 平台占比**：圆环图展示平台分布（支持按 Token / 轮数切换）
- **🍩 模型占比**：展示模型调用（支持对话模型/全部模型，按 Token/次数切换，支持零值隐藏与“其它”展开）
- **📈 趋势概览**：折线图展示趋势变化（按小时/天/月聚合）
- **📑 明细表格**：会话明细列表，支持搜索 ID 与多列双向排序
